# Dr. S. Narendran — Academic Portfolio

A responsive single-page academic/research portfolio designed for Vercel.

## Deploy to Vercel
1. Put this folder in a GitHub repository.
2. Sign in to Vercel with GitHub.
3. Import the repository.
4. Framework preset: **Other** (no build command needed).
5. Deploy.

Before publishing, replace placeholder social links/email and refine dates, publications, profile photo, CV and institutional details.
